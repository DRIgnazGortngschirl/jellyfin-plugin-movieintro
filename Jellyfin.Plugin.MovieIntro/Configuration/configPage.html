Movie Intro

Plays an intro clip before movies and/or series episodes (cinema mode). The clip must live in a library folder that has been scanned. Clients need cinema mode switched on (web: Settings → Playback). Intros are not played when resuming.

General

Master switch. When off, no intro is played anywhere.

Intro clip

Lists videos the server knows about (e.g. a Home Videos library holding the clip). Picking one fills in the path below.
You can also type a path by hand, e.g. /intros/intro.mp4. The file must be inside a scanned library.

Series (episodes)

"First" means the lowest episode number that exists in the library. Specials (season 0) never count as first.
Listed series and seasons follow the "Which episodes" setting. A listed episode always gets the intro.
